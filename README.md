This is a server and client python socket demostration.It connects two devices through low level socket programming
To use it follow the instructions below:
1)First make sure you have python installed in your local device
2)Install virtual box and setup a virtual machine that will act as either the client or server(It is interchangable)
3)Open client.py file and add a host ip for the client to connect to
4)Start the server on either your virtual machine or local machine
5)Start the client and watch the magic of sockets work
